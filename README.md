# NAGISA STAY

海辺の一棟貸し宿をテーマにした、架空のポートフォリオ用サイトです。

## About

実在する企業・宿泊施設の公式サイトではありません。固有名詞、施設情報、住所、連絡先、写真、文章は実案件から切り離したデモ用のオリジナルです。

## Features

- レスポンシブ対応の宿泊施設サイト
- スクロール連動のコンテンツ表示
- モバイルナビゲーション
- 宿泊施設カード、Journal、予約フォームのUI
- GitHub Pages でそのまま公開可能な静的構成

## Run locally

`index.html` をブラウザで開くか、任意の静的サーバーで配信してください。

```powershell
python -m http.server 4173
```

ブラウザで `http://localhost:4173/` を開きます。
